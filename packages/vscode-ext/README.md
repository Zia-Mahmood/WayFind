# @wayfind/vscode-ext

The VS Code extension: map→editor go-to-code (exact `file:line`), editor→map focus sync (debounced cursor tracking), executed-line highlighting for a selected trace range, and a "⏺ record this test" code lens. Talks to the app/CLI over a local socket; renders the shared React UI in a webview.

**Status:** not yet implemented — one direction in [M3](../../docs/ROADMAP.md), bidirectional in M5.

# @wayfind/app

The desktop application: a Tauri shell around the shared React UI (map view, timeline scrubber, search, breadcrumbs, state inspector). The same UI components are reused by `vscode-ext` in a webview — app-only code here is the shell, windowing, and file associations (`.wayfind-trace`).

**Status:** not yet implemented — assembled across [M2–M5](../../docs/ROADMAP.md); cross-platform builds in M6.
